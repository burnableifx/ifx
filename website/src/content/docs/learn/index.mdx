Start with a disposable local file, then add references, lifecycle controls, health checks, and the daemon boundary. The final local labs boot real Debian guests with QEMU and expose the live deployment through the Explorer.

<Steps>

1. **See reconciliation in five minutes.** Run the first stack, apply it twice, introduce drift, and let ifx repair the observed system.

   [Start with Lab 1 →](/learn/labs/01-first-stack/)

2. **Learn how the graph is formed.** Pass outputs between resources, add explicit ordering, and understand replacement and protection.

   [Continue through the lab sequence →](/learn/labs/)

3. **Build real local infrastructure.** Download a verified cloud image, create a rootless network, boot three VMs, and configure them through the same `host.*` resources used in the cloud.

   [Run the QEMU lab →](/learn/labs/08-qemu/)

4. **Operate instead of guessing.** Inspect topology, health, drift, approvals, retries, and durable execution history through `ifxd`.

   [Use the Deployment Explorer →](/learn/labs/09-deployment-explorer/)

</Steps>
